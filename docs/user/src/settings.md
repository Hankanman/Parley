# Settings

Open **Settings** from the sidebar or the tray menu. Changes are saved as soon as you make them.

| Page | What's there |
|---|---|
| **Recording** | Recordings folder, default microphone and system audio, auto-save, live action items, call detection. See [Recording a meeting](recording.md). |
| **Transcription** | Whisper model, custom vocabulary, model downloads. See [Transcription and AI models](models.md#transcription-whisper). |
| **Summary** | AI provider and model, API keys, default template, summary output language, transcription language, auto-summarize. See [Transcription and AI models](models.md#language-model-for-summaries-and-ask). |
| **Templates** | Create, duplicate and edit meeting templates, reorder sections, preview their layout, and choose a default. Built-in templates can be customized and restored. |
| **Notifications** | Which desktop notifications to show. |
| **Calendar** | Calendar feeds. See [Calendar and briefs](calendar.md). |
| **Integrations** | The MCP server and the Markdown export folder. See [Using Parley with Claude (MCP)](mcp.md) and [Exporting](meetings.md#exporting). |
| **Appearance** | Theme: *Follow system*, *Light* or *Dark*. |
| **About** | Version, and links to the repository and to report an issue. |

## Notifications

Under **General**:

- **Recording notifications** turns the four recording notifications below on or off together.
- **Notification sound** asks your desktop to play its message sound with each notification.
- **Manual Do Not Disturb** silences all of Parley's notifications. Your desktop's own Do Not Disturb mode also holds them back.

Under **Events**, choose which notifications Parley shows:

| Event | Default |
|---|---|
| Recording started | Off |
| Recording stopped | Off |
| Recording paused / resumed | On |
| Transcription complete | On |
| Meeting reminders | On |
| System errors | On |

**Send test notification** checks that notifications reach your desktop.

Call-detection prompts are controlled from **Settings → Recording → Meeting detection** instead.
